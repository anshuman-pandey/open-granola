**विकासाधीन प्रीव्यू।** Open Granola आपके माइक्रोफ़ोन की आवाज़ रिकॉर्ड करता है, स्थानीय Whisper से उसे लिखित ट्रांसक्रिप्ट में बदलता है और स्थानीय मॉडल या आपके जोड़े हुए प्रदाता से नोट्स बनाता है। आपकी लाइब्रेरी स्थानीय SQLite डेटाबेस में रहती है। क्लाउड से सारांश बनवाने पर ट्रांसक्रिप्ट का टेक्स्ट चुने हुए प्रदाता को भेजा जाता है।

सिस्टम ऑडियो कैप्चर अभी उपलब्ध नहीं है: यह बिल्ड हेडफ़ोन से सुनाई देने वाले कॉल के दूसरे पक्ष की आवाज़ रिकॉर्ड नहीं करता। वास्तविक माइक्रोफ़ोन और मॉडल वाले सत्रों, प्रदाता खातों और पैकेज किए गए रिलीज़ का लक्षित हार्डवेयर पर शुरू से अंत तक परीक्षण अभी बाकी है। ब्राउज़र प्रीव्यू में स्पष्ट रूप से चिह्नित नमूना मीटिंग हैं।

## अभी क्या उपलब्ध है

- **माइक्रोफ़ोन ट्रांसक्रिप्शन:** स्थानीय `whisper.cpp`, समय सहित ट्रांसक्रिप्ट के हिस्से और लाइव ट्रांसक्रिप्ट।
- **सारांश प्रदाता चुनना:** अंतर्निहित Qwen, LM Studio, OpenAI API, Claude API, कस्टम OpenAI-compatible एंडपॉइंट और प्रयोगात्मक Sign in with ChatGPT।
- **कनेक्शन परीक्षण:** कृत्रिम नमूना टेक्स्ट से चुने हुए सारांश मॉडल की जाँच होती है; कोई मीटिंग नहीं भेजी जाती। इससे माइक्रोफ़ोन कैप्चर या Whisper की जाँच नहीं होती।
- **सहेजी गई मीटिंग की रिकवरी:** सारांश बनाने से पहले ट्रांसक्रिप्ट सहेजा जाता है। सारांश विफल हो जाए तो दोबारा रिकॉर्ड किए बिना फिर कोशिश कर सकते हैं। नोट्स दोबारा बनाते समय मौजूदा कार्यों की ID और उनके पूरे होने की स्थिति सुरक्षित रहती है।
- **प्रोसेसिंग की जानकारी:** सहेजी गई मीटिंग में कॉन्फ़िगर किया गया मॉडल/प्रदाता और सारांश की स्थिति दर्ज होती है, ताकि बाद में सेटिंग बदलने पर भी पता रहे कि नोट कैसे बना था।
- **स्थानीय लाइब्रेरी:** कीवर्ड खोज, खोजे गए टेक्स्ट पर सवाल, कार्य, प्रतिबद्धताएँ, Markdown प्रॉम्प्ट, JSON इंपोर्ट और Markdown एक्सपोर्ट।
- **डेटा रखने की अवधि:** पुराने हो चुके नोट्स हटाएँ या स्थानीय लाइब्रेरी पूरी तरह मिटाएँ। इसकी सीमाएँ [गोपनीयता](../../PRIVACY.md) में पढ़ें।

बनाए गए नोट्स और प्रतिबद्धताओं की समीक्षा ज़रूरी है। वक्ता की पहचान, अर्थ-आधारित/vector खोज, कैलेंडर इंटीग्रेशन, किसी खास मीटिंग सेवा से सीधे इंपोर्ट, एन्क्रिप्टेड ऑडियो प्लेबैक और नेटिव सिस्टम ऑडियो कैप्चर अभी लागू नहीं हैं।

## मॉडल और कनेक्शन

ट्रांसक्रिप्शन और सारांश बनाना अलग काम हैं। **रिकॉर्डिंग के लिए हर सारांश प्रदाता के साथ अभी स्थानीय Whisper आवश्यक है।** इस रिलीज़ में क्लाउड ट्रांसक्रिप्शन API नहीं है।

| सारांश का विकल्प | सेटअप | Open Granola क्या भेजता है |
|---|---|---|
| अंतर्निहित स्थानीय Qwen | `qwen3-4b-q4.gguf` इंस्टॉल करें | प्रदाता को कोई अनुरोध नहीं |
| LM Studio | इसका OpenAI-compatible सर्वर शुरू करें; `http://127.0.0.1:1234/v1` और लोड किए गए मॉडल की ID डालें | इसी डिवाइस के सर्वर को टेक्स्ट |
| OpenAI API | आपकी API key और समर्थित मॉडल ID | OpenAI को टेक्स्ट; API का शुल्क लागू होता है |
| Claude API | आपकी Anthropic API key और मॉडल ID | Anthropic को टेक्स्ट; API का शुल्क लागू होता है |
| OpenAI-compatible | संगत base URL, मॉडल ID और वैकल्पिक key; जैसे स्थानीय Ollama सर्वर | कॉन्फ़िगर किए गए सर्वर को टेक्स्ट |
| ChatGPT प्लान — प्रयोगात्मक | **Continue with ChatGPT** चुनें, पात्र प्लान के उपयोग की अनुमति दें और मॉडल चुनें | अधिकृत प्लान के ज़रिए OpenAI को टेक्स्ट |

ChatGPT विकल्प [ओपन सोर्स/स्थानीय ऐप के आधिकारिक साइन-इन फ़्लो](https://developers.openai.com/siwc/token-sharing-open-source) का उपयोग करता है। इससे आपकी मौजूदा ChatGPT बातचीत का एक्सेस नहीं मिलता। पात्रता और मॉडल की उपलब्धता खाते और प्रदाता पर निर्भर करती है। वास्तविक खाते से इस इंटीग्रेशन का शुरू से अंत तक सत्यापन अभी नहीं हुआ है। यहाँ यह टेक्स्ट अनुरोध संभालता है; [इस प्रीव्यू में ऑडियो ट्रांसक्रिप्शन समर्थित नहीं है](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)।

Claude को API key से जोड़ा जाता है; इस ऐप में Claude के उपभोक्ता खाते से लॉगिन नहीं है। OpenAI API keys और ChatGPT प्लान साइन-इन अलग विकल्प हैं।

### सारांश मॉडल जोड़ें

सेटअप गाइड: [LM Studio](../integrations/LM_STUDIO.md) · [Ollama](../integrations/OLLAMA.md)।

1. डेस्कटॉप ऐप में **Settings → Models & connections** खोलें।
2. प्रदाता चुनें और उसकी सटीक मॉडल ID डालें। कस्टम सर्वर के लिए उसके दस्तावेज़ में दिया API base URL डालें।
3. ChatGPT के लिए अपना खाता जोड़ें और **Load available models** चुनें, या अपने खाते में समर्थित मॉडल की ID डालें। डिवाइस से बाहर टेक्स्ट भेजने वाले विकल्प के लिए इसकी अनुमति वाली सेटिंग चालू करें। इसमें असिस्टेंट और प्रॉम्प्ट द्वारा उपयोग किए जाने वाले संबंधित सहेजे गए नोट्स भी शामिल हैं।
4. सेटिंग सहेजें और **Test connection** चलाएँ।
5. लंबे सत्र से पहले माइक्रोफ़ोन का छोटा सत्र रिकॉर्ड करके ट्रांसक्रिप्ट और नोट्स जाँचें।

रिमोट एंडपॉइंट के लिए HTTPS आवश्यक है; बिना एन्क्रिप्शन वाला HTTP केवल `127.0.0.1` जैसे सीधे लिखे loopback IP पते के लिए स्वीकार होता है। LM Studio के लिए ऊपर दिया IP पता उपयोग करें। कस्टम सर्वर की संगतता जाँचना आवश्यक है: OpenAI-compatible कहने से यह गारंटी नहीं मिलती कि हर एंडपॉइंट समान अनुरोध फ़ील्ड संभालता है। मॉडल विफल होने पर ऐप अपने-आप स्थानीय से क्लाउड प्रोसेसिंग पर नहीं जाता।

Keys नेटिव कोड में संभाली जाती हैं और उपलब्ध होने पर ऑपरेटिंग सिस्टम के credential store में सहेजी जाती हैं। यदि वहाँ सहेजना संभव न हो, तो ऐप उन्हें केवल मौजूदा सत्र की मेमोरी में रखता है और यह स्थिति दिखाता है। Credentials मीटिंग डेटाबेस या ब्राउज़र स्टोरेज में नहीं रखे जाते। स्थानीय सर्वर भी अनुरोध आगे भेज सकता है; Open Granola से टेक्स्ट मिलने के बाद क्या होता है, यह उस सर्वर की सेटिंग पर निर्भर है।

## प्रीव्यू आज़माएँ

### ब्राउज़र वर्कस्पेस

```sh
git clone https://github.com/anshuman-pandey/open-granola.git
cd open-granola
npm ci
npm run dev
```

ब्राउज़र वर्कस्पेस नमूना मीटिंग दिखाता है। यह ऑडियो रिकॉर्ड नहीं करता, नेटिव inference नहीं चलाता और प्रदाता के credentials नहीं सहेजता।

### डेस्कटॉप डेवलपमेंट बिल्ड

Rust **1.98 या नया**, Node **22.12 या नया** (Node 24 LTS अनुशंसित), CMake, libclang, C/C++ कंपाइलर और [Tauri की प्लेटफ़ॉर्म आवश्यकताएँ](https://v2.tauri.app/start/prerequisites/) इंस्टॉल करें। Linux पर ALSA, WebKitGTK और कॉन्फ़िगर किए गए PipeWire की डेवलपमेंट dependencies भी चाहिए। macOS बंडल का लक्ष्य macOS 14.4 या नया है। किसी प्लेटफ़ॉर्म की बिल्ड सेटिंग होने का अर्थ वहाँ हार्डवेयर QA पूरा होना नहीं है।

```sh
npm ci
npm run tauri dev
```

Tauri hooks ऐप शुरू करने से पहले स्थानीय inference helper बनाते हैं। रिलीज़ बंडल के लिए:

```sh
npm run tauri build
```

बिल्ड फ़ाइलें `src-tauri/target/release/bundle` में मिलेंगी। Signing, notarization और इंस्टॉल/अपग्रेड परीक्षण रिलीज़ के अलग काम हैं। तैयार होने पर सत्यापित फ़ाइलें [Releases](https://github.com/anshuman-pandey/open-granola/releases) में प्रकाशित करें; यह README तैयार इंस्टॉलर उपलब्ध होने का वादा नहीं करता।

### स्थानीय मॉडल इंस्टॉल करें

Settings में मॉडल की वास्तविक डायरेक्टरी दिखती है: `<app-data>/library/models/`।

- ऑडियो रिकॉर्ड करने के लिए संगत Whisper मॉडल **`whisper-large-v3-turbo.bin`** नाम से इंस्टॉल करें।
- अंतर्निहित सारांश मॉडल का उपयोग करने पर ही संगत GGUF मॉडल **`qwen3-4b-q4.gguf`** नाम से इंस्टॉल करें।
- LM Studio या क्लाउड सारांश मॉडल के साथ Whisper फिर भी आवश्यक है, लेकिन अंतर्निहित Qwen फ़ाइल नहीं।

मॉडल हाथ से इंस्टॉल करने होते हैं। ऐप आपके लिए डाउनलोड, रुके हुए डाउनलोड फिर शुरू करना या प्रकाशक के checksum की जाँच नहीं करता। मॉडल विश्वसनीय प्रकाशक से लें और उनका फ़ॉर्मैट व लाइसेंस जाँचें। फ़ाइल न मिलने या अमान्य होने पर सेटअप त्रुटि दिखाई जाती है।

## मीटिंग कैसे प्रोसेस होती है

```text
माइक्रोफ़ोन → स्थानीय Whisper → सहेजा गया स्थानीय ट्रांसक्रिप्ट
                                      ↓
                         चुना हुआ स्थानीय/सर्वर/क्लाउड मॉडल
                                      ↓
                            नोट्स, कार्य, प्रतिबद्धताएँ
```

नोट्स, ट्रांसक्रिप्ट और प्रोसेसिंग की जानकारी स्थानीय रूप से सहेजी जाती है; डेटाबेस पर ऐप-स्तरीय एन्क्रिप्शन नहीं है। ट्रांसक्रिप्ट सहेजे जाने के बाद सारांश विफल हो, तो सहेजी गई मीटिंग पर फिर कोशिश करें। कैप्चर अभी केवल मेमोरी में हो और ऐप क्रैश हो जाए, तो इस सुविधा से उसे वापस नहीं पाया जा सकता। ऑडियो RAM में रहता है; उसे जानबूझकर रिकॉर्डिंग फ़ाइल में नहीं लिखा जाता।

## गोपनीयता, सरल शब्दों में

- स्थानीय मॉडल डिफ़ॉल्ट हैं। डिवाइस से बाहर टेक्स्ट प्रोसेस करने के लिए प्रदाता की सेटिंग और अनुमति आवश्यक है।
- प्रदाताओं और ChatGPT साइन-इन के लिए नेटिव नेटवर्किंग चालू है। यह बिल्ड **ऑपरेटिंग सिस्टम द्वारा नेटवर्क से अलग किया गया air gap नहीं है**।
- Webview केवल बंडल में मौजूद assets और स्थानीय ऐप IPC तक सीमित है। प्रदाता के अनुरोध नेटिव कोड से जाते हैं।
- ऐप में telemetry या Open Granola की cloud-sync सेवा नहीं है। जुड़े हुए प्रदाताओं की अपनी डेटा नीतियाँ हैं।
- स्थानीय रिकॉर्ड मिटाने से प्रदाता के पास मौजूद डेटा, एक्सपोर्ट की गई फ़ाइलें, OS snapshots या backups नहीं मिटते।

स्टोरेज, credentials, नेटवर्क और डेटा मिटाने की जानकारी के लिए [PRIVACY.md](../../PRIVACY.md) और [SECURITY.md](../../SECURITY.md) पढ़ें।

## अगली प्राथमिकताएँ

[प्रतिस्पर्धी समीक्षा](../COMPETITIVE_RESEARCH.md) में दस बड़े संबंधित रिपॉज़िटरी और सात अधिक निकट या आस-पास के उत्पादों का अध्ययन किया गया। प्राथमिकताएँ उपयोगकर्ताओं की बार-बार आने वाली समस्याओं से तय होती हैं, प्रतिस्पर्धी के README में सुविधाओं की संख्या से नहीं:

1. नए इंस्टॉल से वास्तविक मॉडल और प्रदाता खातों के साथ पूरा माइक्रोफ़ोन वर्कफ़्लो सत्यापित करना; मॉडल सेटअप और पैकेजिंग बेहतर बनाना।
2. निर्धारित प्लेटफ़ॉर्म सूची पर सिस्टम ऑडियो, डिवाइस बदलाव, ताज़ा सिग्नल की जानकारी और लंबी रिकॉर्डिंग लागू करना व जाँचना।
3. निर्णयों और कार्यों को ट्रांसक्रिप्ट के अंशों से जोड़ना; AI के अनुमान को पुष्ट प्रतिबद्धता मानने से पहले समीक्षा करना।
4. शब्दावली सुधार, स्पष्ट भाषा चयन और लंबी मीटिंग की ऐसी प्रोसेसिंग जोड़ना जिसे रुकने पर फिर शुरू किया जा सके।
5. मूल रिकॉर्डिंग भरोसेमंद होने के बाद चुनिंदा टेक्स्ट शेयरिंग और सीमित agent access पर काम करना।

ये नियोजित क्षमताएँ हैं। शोध और स्वचालित परीक्षण यह सिद्ध नहीं करते कि ऐप आपके मीटिंग सेटअप पर काम करता है।

## डेवलपमेंट जाँच

```sh
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
```

नेटिव परीक्षणों के लिए संबंधित प्लेटफ़ॉर्म की बिल्ड आवश्यकताएँ चाहिए। कैप्चर, credentials या डेटा प्रबंधन बदलने से पहले [आर्किटेक्चर](../ARCHITECTURE.md), [सुरक्षा नीति](../../SECURITY.md) और [योगदान गाइड](CONTRIBUTING.hi.md) पढ़ें।
