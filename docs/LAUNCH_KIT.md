# Development preview messaging

Open Granola is an Apache-2.0 local meeting notebook. The browser preview demonstrates the workspace with labeled sample data. Native development builds support microphone transcription using manually installed Whisper models, local notes with llama.cpp, searchable transcripts, JSON import and Markdown export.

## Before announcing a release

- Validate the tagged source on macOS, Windows and Linux with real models and microphone hardware.
- Complete signing/notarization and test install, upgrade, permissions and uninstall.
- Publish actual downloadable assets before linking an install button to them.
- Keep the README, landing page and privacy policy consistent with the tested build.

## Claims to avoid

Do not advertise completed system audio capture, diarization, vector search, calendar integration, encrypted playback, model downloading, certified compliance or forensic erasure. Do not compare competitors' pricing/privacy practices without current sources. Do not use a fixed zero counter as network telemetry.
