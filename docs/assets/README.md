# Screenshot provenance

`home.png`, `capture.png` and `note.png` are historical design screenshots. They predate the current provider-enabled, microphone-only development preview. Their system-audio, speaker and zero-network labels do not describe the current implementation.

Use screenshots captured from the exact validated release for a listing or announcement. Keep the browser's sample-data notice visible when demonstrating sample meetings, and use only synthetic content. The matching files under `landing/assets/` have the same historical status.

`logo.svg` is the current Open Granola logo.
