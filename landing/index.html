A notebook for the whole conversation

From listening to following through.

Read the transcript, keep the decision, find the next step. The workspace brings those pieces together without adding another account.

01 / Capture

Microphone to local transcript

The native app uses Whisper on your device. Raw transcripts are saved before optional AI enhancement, so a failed language model does not lose a saved conversation.

02 / Understand

Your notes, with their source

Move between notes and transcript passages, search your library, and ask a local model about matching content. Review generated answers against the original words.

03 / Follow through

Actions that stay connected

Review action items and commitments alongside their source meeting. Import supported JSON notes and take your work with you through Markdown export.

Clear boundaries

Local by design.
Honest about the details.

No application telemetry, cloud inference, or automatic uploads. Your saved notes live in a local SQLite database.

  • Models stay on-device. Install trusted model files manually; the app does not download them.
  • You control retention. Expiry and full-library deletion cover related records and search indexes.
  • Privacy has limits. Notes are not app-encrypted, and deletion cannot erase OS backups or SSD snapshots.

What this preview supports

Microphone capture, local transcription and notes, lexical transcript search, supported JSON imports, and Markdown export.

What still needs building

System audio loopback, speaker diarization, calendar integration, vector search, encrypted audio playback, and mobile pairing. Microphone capture alone does not capture remote participants through headphones.

Before production use

Real-model and hardware testing, signed release packaging, and platform validation are required. macOS release network restrictions differ from Windows, Linux and development builds.

Built in the open

Start with the source.

Run the browser sample workspace with Node 24 LTS. For the desktop app, add stable Rust, CMake and the Tauri platform prerequisites. 

git clone https://github.com/anshuman-pandey/open-granola.git
cd open-granola
npm ci
npm run dev
